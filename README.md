# 🚀 Git & GitHub Mastery

A hands-on repository documenting my journey to mastering **Git and GitHub** for real-world software development and DevOps workflows.

This project focuses on practical learning rather than theory. Every concept is practiced through real commands, experiments, challenges, mistakes, troubleshooting, and documented solutions.

---

## 🎯 Purpose

The goal of this repository is to build a strong, practical understanding of Git and GitHub and learn how they are used in professional development and DevOps environments.

I am using this repository to document:

* Git fundamentals
* Version control workflows
* Branching and merging
* Merge conflicts
* Rebasing
* Remote repositories
* GitHub collaboration
* Pull requests
* GitHub workflows
* Git best practices
* Troubleshooting
* DevOps-oriented Git workflows

```bash

```

### Branching

```bash

git checkout
git merge
```

Topics include:

* Creating branches
* Switching branches
* Feature branches
* Merging branches
* Fast-forward merges
* Three-way merges
* Deleting branches

### Merge Conflicts

Practical exercises covering:

* Understanding conflicts
* Identifying conflicting files
* Resolving conflicts manually
* Staging resolved files
* Completing merges
* Preventing unnecessary conflicts

### Git Rebase

```bash
git rebase
git rebase -i
```

Learning:

* Rebase vs merge
* Updating branches
* Interactive rebasing
* Cleaning commit history
* Squashing commits
* Reordering commits
* Editing commits

### Remote Repositories

```bash
git remote
git push
git pull
git fetch

```

Learning how local repositories communicate with remote repositories.

# 🔥 Practical Labs

This repository contains hands-on labs and experiments.

Examples include:

### Lab 01 — Git Installation & Configuration

Learn how to install Git and configure:

* Username
* Email
* Default branch
* Credential/authentication settings

### Lab 02 — First Git Repository

Practice:

```bash
git init
git add .
git commit
git log
```

### Lab 03 — Branching

Create and manage feature branches.

### Lab 04 — Merge Conflicts

Intentionally create conflicts and resolve them.

### Lab 05 — Git Rebase

Practice rebasing and cleaning commit history.

### Lab 06 — GitHub Remote Repository

Connect a local project to GitHub and push changes.

### Lab 07 — SSH Authentication

Configure SSH authentication for GitHub.

### Lab 08 — Pull Requests

Create branches, push changes, and create Pull Requests.

### Lab 09 — Git Recovery

Practice recovering from common mistakes using:

```bash
git restore
git reset
git reflog
```

### Lab 10 — Real-World Workflow

Build a complete Git workflow similar to what is used in DevOps teams.

This repository follows a **learn → practice → break → fix → document** approach.

Instead of only memorizing commands, I aim to understand:

> **What does the command do?**
> **Why do we use it?**
> **When should we use it?**
> **What can go wrong?**
> **How do we fix it?**
